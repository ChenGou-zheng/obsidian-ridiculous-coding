# Ridiculous Coding for Obsidian

Transform your Obsidian editing into an epic adventure! Blips, booms, screen shake, XP levels, and fireworks — every keystroke counts.
## Features

- **Blips** — Colorful animations when typing characters
- **Booms** — Explosive effects when deleting
- **Screen Shake** — Editor jitter that responds to typing intensity
- **Newline Animations** — Special effects for line breaks
- **Fireworks** — Celebration animations on level up
- **XP & Leveling System** — Earn experience points for every character typed, with progressive leveling
- **Sound Effects** — Satisfying audio feedback for typing, deleting, and leveling up
- **Control Panel** — Sidebar view showing your level, XP progress, and quick effect toggles
- **Customization** — Toggle every effect independently in Settings
- **Accessibility** — Reduced effects mode disables all visual/sound distractions while keeping XP

## Installation

1. Download from Obsidian Community Plugins (search "Ridiculous Coding")
2. Enable in Settings → Community Plugins
3. Configure effects in Settings → Ridiculous Coding
4. Open the control panel from the ribbon icon or command palette

## Manual Installation

Copy `main.js`, `manifest.json`, `styles.css`, and the `media/` folder to your vault's `.obsidian/plugins/obsidian-ridiculous-coding/` directory.

## Settings

| Setting | Default | Description |
|---------|---------|-------------|
| Blip effects | On | Show animations when typing |
| Explosion effects | On | Show boom effects when deleting |
| Character labels | On | Show typed character with effects |
| Screen shake | On | Enable editor shake |
| Shake amplitude | 6px | Maximum shake displacement |
| Sound effects | On | Play audio feedback |
| Fireworks | On | Celebrate level-ups |
| Base XP | 50 | XP level-up curve base |
| Status bar | On | Show level/XP in status bar |
| Reduced effects | Off | Disable all effects, keep XP |

## Commands

- **Ridiculous Coding: Show Panel** — Open the control panel
- **Ridiculous Coding: Reset XP** — Reset experience and level
